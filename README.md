# Dashboard Penjualan yang Mudah Dipahami dan Aksesibel

## Studi kasus
Studi kasus: dashboard interaktif ringkas yang menampilkan KPI, grafik penjualan, dan tabel data. Prinsip HCI diterapkan melalui label jelas, kontras, struktur sederhana, dan teks alternatif/penjelas.

## Implementasi
Kode pada proyek ini menunjukkan penerapan konsep materi dalam skala mini. Data contoh disediakan di folder `data/`.

## Cara menjalankan
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Interpretasi dan batasan
Gunakan hasil sebagai demonstrasi alur kerja. Untuk penerapan nyata, gunakan data yang dapat dipertanggungjawabkan, lakukan validasi, dan dokumentasikan asumsi serta keterbatasan.
